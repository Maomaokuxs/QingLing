# 清聆（song_dedup）

Android 本地音乐去重工具：扫描媒体库，找出重复/相似的歌曲，按音质自动勾选较差版本，一键移入回收站（可撤销）。

## 功能

- **四层递进识别**：标题/歌手归一化 → 时长锚定（跨格式/转码副本）→ 标题模糊匹配 → 文件内容哈希
- **音质评估**：格式权重（FLAC/WAV > AAC > MP3…）+ MediaStore 真实码率（取不到时回退估算），自动保留每组最佳
- **安全删除**：先移入应用内回收站再删，支持撤销、恢复、导出清单
- **试听**：每首歌可试听 10 秒再决定删不删
- **指纹缓存**：文件内容哈希按修改时间缓存，二次扫描秒出

## 识别原理

| 层级 | 方法 | 解决什么 |
|------|------|----------|
| 1 | 标题+歌手归一化（去括号/符号，Unicode 感知） | 同歌多版本最常见情况 |
| 2 | 时长 ±2s + 标题相似度 ≥0.6 | 跨格式/转码：mp3 与 flac 的同一首歌 |
| 3 | 标题 bi-gram 相似度 + 时长相近（时长分桶） | 标题略有差异的副本 |
| 4 | 文件头 SHA-256 全等 | 文件名不同但字节相同的副本 |

注意：第 4 层是字节级哈希，不是声学指纹，转码过的同一首歌哈希不同——跨格式靠第 2 层。

## 构建

```bash
flutter build apk --release --split-per-abi
# 产物：build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

## 权限

- `READ_MEDIA_AUDIO`（Android 13+）：读取媒体库
- 删除走系统 `MediaStore.createDeleteRequest`，由用户在系统弹窗中确认
