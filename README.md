# 清聆（QingLing）

Android 本地音乐去重工具：扫描媒体库，找出重复/相似的歌曲，按音质自动勾选较差版本，一键移入回收站（可撤销）。

## 功能

- **四层递进识别**：标题/歌手归一化 → 时长锚定（跨格式/转码副本）→ 标题模糊匹配 → 文件头哈希
- **元数据版本细分**：同名组内按文字脚本/版本关键词/歌手/feat. 区分不同语言与版本，拆出的组不自动勾选（宁可漏过，不可错选）
- **音质评估**：格式权重（FLAC/WAV > AAC > MP3…）+ MediaStore 真实码率（取不到时回退估算），自动保留每组最佳
- **安全删除**：先移入应用内回收站再删，支持撤销、恢复、导出清单
- **试听**：每首歌可试听 10 秒再决定删不删
- **增量扫描**：文件清单按路径+修改时间+大小缓存，重扫时只处理新增/变更/删除的文件

## 识别原理

| 层级 | 方法 | 解决什么 |
|------|------|----------|
| 1 | 标题+歌手归一化（去括号/符号，Unicode 感知） | 同歌多版本最常见情况 |
| 2 | 时长 ±2s + 标题相近 + 歌手兼容 + 大小比 ≤30x | 跨格式/转码：mp3 与 flac 的同一首歌 |
| 3 | 标题 bi-gram 相似度 + 时长相近（时长分桶） | 标题略有差异的副本 |
| 4 | 文件头 SHA-256（前 32KB + 大小 + 扩展名） | 文件名不同但字节相同的副本 |

组内验证层：Tier 1~3 出组后跑元数据兼容检查，不兼容的对拆成「同名不同版本」的新组，永不自动勾选。

注意：第 4 层是文件头哈希，不是声学指纹，转码过的同一首歌哈希不同——跨格式靠第 2 层。

## 构建

```bash
flutter build apk --release --target-platform android-arm64
# 产物：build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

## 权限

- `READ_MEDIA_AUDIO`（Android 13+）：读取媒体库
- 删除走系统 `MediaStore.createDeleteRequest`，由用户在系统弹窗中确认
